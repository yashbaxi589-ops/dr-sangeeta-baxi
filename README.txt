DR. SANGEETA BAXI — WEBSITE PROJECT

PROJECT CONTENTS
- index.html: page content and website structure
- style.css: blue colour theme, layout, typography and responsive design
- assets/dr-sangeeta-baxi-portrait.jpg: homepage portrait cropped from your supplied photo
- assets/community-camp-team.jpg: community photo used in the About section
- assets/gallery/: 48 distinct photos/event images from your uploaded files

HOW TO OPEN THE WEBSITE
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Keep index.html, style.css and the assets folder together.

BEFORE PUBLISHING
Update the clinic address, appointment phone number and email address in index.html. These details were not included in the supplied information, so they have not been invented.

IMAGE HANDLING
All unique supplied photo/event images were copied into assets/gallery. Identical duplicate files in repeated ZIP uploads are included only once. The two website reference screenshots were used as design inspiration and are not included as personal gallery photos.

The website uses HTML and CSS only. Google Fonts are loaded online; local system fonts are used as fallbacks.
